# XiaomiHome

The `XiaomiHome` documentation is split into two main documents:

- [User Guide](USER_GUIDE.md)
- [Technical Reference](TECHNICAL_REFERENCE.md)

## What to open

If you want to set up the plugin from the admin page, connect Xiaomi devices, and configure links to osysHome objects, start with [User Guide](USER_GUIDE.md).

If you need implementation details (UDP protocol, message parsing, command generation, model schema, and integration callbacks), open [Technical Reference](TECHNICAL_REFERENCE.md).
