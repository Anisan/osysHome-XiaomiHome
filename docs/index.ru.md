# XiaomiHome

Документация по модулю `XiaomiHome` разделена на два основных файла:

- [Руководство пользователя](USER_GUIDE.ru.md)
- [Техническая документация](TECHNICAL_REFERENCE.ru.md)

## Что открыть

Если нужно настроить модуль через админку, подключить устройства Xiaomi и настроить связи с объектами osysHome, начните с [руководства пользователя](USER_GUIDE.ru.md).

Если нужны детали реализации (UDP-протокол, разбор сообщений, генерация команд, структура моделей и callbacks интеграции), откройте [техническую документацию](TECHNICAL_REFERENCE.ru.md).
