# XiaomiHome - Интеграция шлюза Zigbee Xiaomi

![XiaomiHome Icon](static/XiaomiHome.png)

Интеграция с шлюзом Zigbee Xiaomi для управления устройствами Zigbee Xiaomi через протокол multicast UDP.

## Описание

Модуль `XiaomiHome` предоставляет интеграцию с шлюзом Zigbee Xiaomi для платформы osysHome. Он обеспечивает обнаружение, управление и мониторинг устройств Zigbee Xiaomi через multicast UDP коммуникацию.

## Основные возможности

- ✅ **Multicast UDP**: Коммуникация через протокол multicast UDP
- ✅ **Обнаружение устройств**: Автоматическое обнаружение устройств
- ✅ **Управление устройствами**: Управление устройствами Zigbee
- ✅ **Управление командами**: Управление командами устройств
- ✅ **Связывание свойств**: Связывание команд устройств со свойствами объектов
- ✅ **Связывание методов**: Связывание команд устройств с методами объектов
- ✅ **Интеграция поиска**: Поиск устройств и команд

## Панель администратора

Модуль предоставляет административный интерфейс для:
- Просмотра устройств Zigbee Xiaomi
- Настройки параметров устройств
- Управления командами устройств
- Связывания команд со свойствами

## Конфигурация

- **Ключ шлюза**: Ключ шифрования шлюза Xiaomi
- **Multicast адрес**: 224.0.0.50 (по умолчанию)
- **Multicast порт**: 9898 (по умолчанию)

## Использование

### Добавление устройства

1. Перейдите в модуль XiaomiHome
2. Устройства обнаруживаются автоматически через multicast
3. Настройте ключ шлюза
4. Свяжите команды устройств со свойствами объектов

## Технические детали

- **Протокол**: Multicast UDP
- **Шлюз**: Шлюз Zigbee Xiaomi
- **Типы устройств**: Все устройства Zigbee, поддерживаемые шлюзом Xiaomi
- **Шифрование**: Шифрование на основе ключа шлюза
